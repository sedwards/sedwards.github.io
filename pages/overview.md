# About Updatez.org

Updatez.org focuses on **modernizing legacy software** and bringing useful tools into the modern macOS ecosystem.

Our work includes:

* porting legacy applications
* maintaining macOS builds of open source software
* developing tools that simplify application migration

---

## Areas of Focus

### Software Porting

Helping developers migrate applications from Windows and Unix environments to macOS.

### Apple Silicon Compatibility

Ensuring software runs efficiently on modern Apple hardware.

### Developer Tools

Creating utilities that simplify packaging, dependency analysis, and application deployment.

---

## Our Mission

We believe valuable software should continue to work as platforms evolve.

Our goal is to make it easier for developers and organizations to **preserve useful tools while adapting them to modern operating systems**.
